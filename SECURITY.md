# Security reports

The project's source repository is public under MIT. No supported signed end-user version exists yet. The maintainer is [kvkv602-crypto](https://github.com/kvkv602-crypto).

Do not include API keys, passwords, personal databases, raw listings with private notes, or signing credentials in a public issue. Prefer a minimal reproduction with synthetic data. Repository publication and CI do not require a user's RIA key.

Use GitHub's private vulnerability-reporting facility if the repository's **Security → Report a vulnerability** action is available. That facility has not yet been confirmed as enabled. Otherwise, open a public issue asking for a private reporting channel without describing exploitable details or including secrets. No private address or reporting service is claimed here.

Unsigned development artifacts are not trusted release downloads. A blocked executable or helper is not a reason to disable Windows protections; report the application version and the warning text without uploading credentials or personal data.

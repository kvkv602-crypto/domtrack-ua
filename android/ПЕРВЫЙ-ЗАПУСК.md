# Первый запуск DomTrack UA Android 0.1.0

Это версия для проверки. Установочный APK выдаётся только после сборки; текущий результат записан в BUILD-RESULT.md.

1. Передайте файл APK на Samsung и откройте его в файловом менеджере. Установка выполняется на телефоне; компьютер для дальнейшего поиска не требуется.
2. Откройте «Фильтры»: выберите город, квартиры/дома, комнаты, площадь, этаж и бюджет. При пустых границах бюджета валюта не должна отсеивать объявления.
3. Нажмите «Сохранить поиск и включить наблюдение» и разрешите системные уведомления. В разделе «Ещё» можно включать и выключать отдельные сохранённые поиски.
4. «Проверить» выполняет короткую проверку с продолжением общей очереди. «Полный обход» проходит доступные страницы выбранного города, пока приложение открыто. В «Ещё → Источники и ход обхода» видны позиции и ошибки сайтов. Результаты накапливаются в собственной базе телефона.
5. Для ключа RIA откройте «Ещё → API-ключ DIM.RIA» и введите ключ на телефоне. С Windows он автоматически не переносится; в исходниках и APK ключа нет. Официальный API обновляется отдельной командой с ограничением запросов, а фоновые проверки используют открытые каталоги.
6. Откройте интересующий объект, добавьте его в избранное и настройте наблюдение/порог цены. Начальная история появляется с первого наблюдения; первое сканирование не рассылает уведомления обо всех старых карточках.

## Звук и фон

В «Ещё → Фон, уведомления и экономия заряда» включаются типы событий, работа в фоне и ограничение Wi-Fi. По умолчанию действуют тихие часы **23:00–08:00** по времени телефона. Звук и вибрация каналов дополнительно настраиваются в системном окне уведомлений по кнопке приложения.

Планировщик запрашивает запуск каждые 15 минут. Android и Samsung могут откладывать его; это не обещание проверки каждого объекта ровно раз в 15 минут. При низком заряде работа откладывается. В короткой задаче проверяется до 2 страниц мобильной сети или 4 страниц безлимитной сети, затем сохраняется очередь.

## Дубли и обмен с ПК

Перестановка слов и некоторые разные формулировки учитываются вместе с адресом, характеристиками, контактами и ценой. Цены разных валют сравниваются по одному датированному курсу НБУ. Вероятные совпадения предлагаются для проверки: одинаковая цена сама по себе не объединяет квартиры. Подтверждённая группа показывает минимальную сопоставимую цену и сохраняет исходные предложения.

В «Ещё» доступны зашифрованные резервные копии и файловый импорт/экспорт. Автоматическое сопряжение с ПК и двусторонняя синхронизация пока не выполнены. Для автономного поиска ПК не нужен.

Поддерживаются источники и города из README; охват всех сайтов интернета не заявляется. Android 17, длительная работа в фоне и расход аккумулятора требуют отдельной проверки на устройстве.

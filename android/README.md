# DomTrack UA Android 0.1.0 — development build

Самостоятельный поиск продажи квартир и домов в Украине. Основной режим не требует ПК, облачного сервера или аккаунта DomTrack. Целевое устройство: Samsung Galaxy S25 Ultra с Android 16; Android 17 требует отдельной проверки.

## Реализовано в исходниках

* Локальная SQLite-база и наблюдавшаяся история цены; сохранённые поиски, фильтры по городу, району, типу продавца, комнатам, площади, этажу, этажности и бюджету USD/EUR/UAH.
* Открытые каталоги Rieltor по 24 городам; DOM.RIA, OBYAVA и Domik по проверенным маршрутам Запорожья. Последовательный обход каталогов с сохранением позиции. Отсутствие карточек не выдаётся за отсутствие объявлений.
* Планировщик Android WorkManager с интервалом 15 минут. В короткой проверке до 2 страниц в мобильной сети / 4 страниц в безлимитной сети, с очередью разделов, кэшированием HTTP, проверкой robots.txt и паузами после ошибок. Интервал относится к запуску задачи, а не гарантии обновления каждого объявления за 15 минут. Doze, ограничения Samsung и ОС могут откладывать запуск. Полный обход выполняется, пока приложение открыто.
* Системные уведомления со звуком/вибрацией о новых объявлениях, росте/снижении цены и изменениях выбранных объектов, пересечении порога. Настройки отдельных каналов, тихие часы, история событий. Для них пользователь разрешает уведомления. Первое наблюдение страницы формирует базу без массовой рассылки.
* Официальный курс НБУ на запрошенную дату, без вымышленных курсов и ложных событий при изменении валютного курса.
* Избранное и заметки офлайн, сравнение до 5 объектов, карта OpenStreetMap с координатами источника и территорией поиска, добавление через системное «Поделиться», ручные наблюдения и импорт структурированных отдельных страниц с явным признаком продажи.
* Зашифрованная резервная копия AES-GCM с паролем, импорт/экспорт файлов для дополнительного обмена с ПК; ключ API в экспорт не включается. Ключ RIA шифруется ключом Android Keystore.
* Открытие исходных контактов и маршрута, создание встречи в приложении календаря без разрешения на чтение всего календаря.

## Границы версии

Это первая версия для проверки, а не заявление о готовности профессионального продукта. Охват всего интернета не гарантируется; другие города отдельных площадок требуют проверки адаптеров. Не все страницы предоставляют координаты, телефоны или структурированные данные. При отсутствии данных они не угадываются. Физическое устройство Samsung и расход аккумулятора требуют измерения на телефоне.

Автоматическое сопряжение с ПК пока не реализовано; доступен обмен файлами. Данные Android и ПК имеют независимые исходные базы. Статус функций и проверки фиксируется в BUILD-RESULT.md после сборки. APK разработки не является публикацией в Google Play и не гарантирует отсутствие предупреждений при установке из файла.

## Сборка

JDK 17, Gradle 8.13, Android SDK 36, Android Gradle Plugin 8.13.2. Из корня проекта: `gradle testDebugUnitTest assembleDebug lintDebug`. CI использует отдельный workflow Android, не изменяет Windows EXE, не обращается к локальным ключам и базам.

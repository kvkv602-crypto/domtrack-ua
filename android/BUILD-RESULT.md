# Состояние Android-проекта

Подготовлен отдельный проект самостоятельного Android-приложения. Готового APK в этой папке пока нет.

Проверено: Java-parser успешно разобрал 18 Java-файлов, включая тесты; Java-код отформатирован Prettier Java. Это проверка синтаксиса, а не компиляция, выполнение JUnit или проверка Android/Samsung. JUnit-регрессии валют, событий, порогов, идентичности ссылок, сравнения цен и шифрования подготовлены для запуска в Gradle.

Не подтверждено: сборка APK, Android lint, установка, звук и фоновая работа на физическом Samsung S25 Ultra, совместимость Android 17 и реальный расход аккумулятора. Не выполнено автоматическое сопряжение с ПК. Фактический охват сайтов ограничен адаптерами, указанными в README.

Для сборки подготовлена локальная ветка `android-standalone` отдельной копии ранее одобренного публичного MIT-проекта `kvkv602-crypto/domtrack-ua`. В неё включены только исходники Android и workflow. Windows-база, ключ RIA, пароли, EXE и личные фотографии в ней отсутствуют.

Сборка остановилась на инструментах среды: загрузка архивов JDK через два официальных источника завершилась тайм-аутами; Java/SDK здесь не установлены. Запуск Git Credential Manager этой сессией возвращает `EPERM`, поэтому ветка не была отправлена на GitHub. Соединение Windows Computer Use отсутствует (`native pipe is unavailable`). Эти ошибки не являются результатом тестирования приложения и не скрываются за сообщением о готовности.

Подготовлен пользовательский запуск сборки: соседний файл `../Запустить-сборку-Android.cmd`. Он отправляет уже подготовленную локальную ветку обычным Git от имени вошедшего пользователя. GitHub Actions затем запускает Gradle, JUnit, Android lint, собирает тестовый APK и проверяет его подпись. Артефакт появляется только при успешном завершении. Ссылка на Actions открывается после отправки.

# Android build evidence

Текущая версия исходников: 0.3.1/code5. Workflow android.yml выполняет JVM-тесты, debug/release сборку, lint и Android16-проверки; доказательства упаковываются в артефакт DomTrack-Android-development. Release APK из CI не содержит локального ключа подписи и подписывается владельцем отдельно после проверки.

До этих изменений подтверждена 0.3.0: commit14f978fbbae44b03c37fff32de2b36e3916d8bc5, GitHub Actions42492448081, 110 JVM и22 Android16 проверки, повторный WorkManager после завершения процесса при выключенном экране через17мин44.705сек. Это историческое свидетельство и не заменяет результаты новых изменений.

Номер запуска, точный SHA исходников, проверки и подпись переданной0.3.1 сборки фиксируются в отчёте доставки после завершения CI. Новые проверки охватывают регистрацию текущего поиска обычной кнопкой, удаление задачи из недавних приложений, карту с группами цен и выбором оформления, объёмные здания и просмотр фото в памяти. Успех компиляции не доказывает доступность всех сайтов, Android17, физический Samsung или расход его аккумулятора. Windows в этой сборке не изменяется; пользовательская база и ключи в Android CI не отправляются.

# Android build evidence

Текущая версия исходников: 0.3.0/code4. Workflow android.yml выполняет JVM-тесты, debug/release сборку, lint и Android16-проверки; доказательства упаковываются в артефакт DomTrack-Android-development. Release APK из CI не содержит локального ключа подписи и подписывается владельцем отдельно после проверки.

До этих изменений подтверждена 0.2.1: commit14596c235ba5157ae79850b52b0dc46f3b49520a, GitHub Actions42234140211, 55 JVM и10 Android16 проверок, повторный WorkManager при выключенном экране через15мин10сек. Это историческое свидетельство и не заменяет результаты новых изменений.

Номер запуска, точный SHA исходников, проверки и подпись переданной0.3 сборки фиксируются в отчёте доставки. Успех компиляции не доказывает доступность всех сайтов, Android17, физический Samsung или расход его аккумулятора. Windows в этой сборке не изменяется; пользовательская база и ключи в Android CI не отправляются.

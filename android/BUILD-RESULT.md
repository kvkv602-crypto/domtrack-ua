# Android 0.2.0 — ожидается сборка

Изменения описаны в CHANGES-0.2.md. Компиляция, тесты устройства и новый APK требуют запуска GitHub Actions. Проверка синтаксиса не заменяет эти тесты.

Предыдущий проверенный APK 0.1.0 сохранён отдельно в outputs и не содержит изменений 0.2.0.

Сертификат отладки создаётся на CI и отличается от сертификата 0.1.0. Android может отклонить обновление поверх старой версии. Перед заменой сохраните зашифрованную резервную копию через «Ещё». API-ключ в неё не входит. Не удаляйте старую версию до сохранения нужных данных.

# Подготовка DomTrack UA к Microsoft Store

Проверено 28 октября 2026 года. Исходники версии 1.3.0, контракт API4. Репозиторий закрытый; права на собственный код не переданы по открытой лицензии.

## Результат

Подготовлен путь сборки MSIX для закрытой аудитории Store. Настоящих реквизитов издателя и продукта Partner Center пока нет. **Файл MSIX не создан, приложение не установлено, сертификация и подпись Microsoft не получены.** Блокировка предыдущего EXE версии 1.2.0 остаётся нерешённой.

Новая личная регистрация издателя требует проверки документа и селфи. Проект не заменяет и не обходит эту проверку. Без подтверждённого издателя нельзя завершить выбранный путь Store. Инструкция: [README](README.md).

## Что подготовлено

- Desktop/full trust manifest x64 и обязательные точные параметры Partner Center. Пустые реквизиты отклоняются до записи файлов.
- Отдельная папка данных Store по стабильному имени семейства пакета; профиль WebView2 вне каталога установки. Автоматического копирования старой базы и ключа нет.
- Native bridge внутри приложения для Windows DPAPI CurrentUser и запроса всплывающих сообщений. Вход/выход JSON ограничены; ключи не передаются в аргументах командной строки. Store-маркер запрещает переход к PowerShell при отсутствии или отказе native bridge.
- Явный список 98 файлов будущего payload. PS1, SFX, исходники сборки, базы, ключи и журналы не выбираются. Манифест, Store-маркер и изображения создаются отдельно сборщиком.
- Официальные Node.js, WebView2 SDK и Windows SDK BuildTools закреплены контрольными суммами; подписи поставщиков проверены. SDK восстановлен в рабочую папку без системной установки.
- Только ручной GitHub workflow; отправка в репозиторий не запускает CI, публикацию, подписание или установку.
- В интерфейсе добавлены сведения о конфиденциальности и статус системных уведомлений. Успешный запрос уведомления не означает, что Windows его показала.

До подачи остаются подтверждённый издатель, доступный URL политики конфиденциальности, актуальные снимки интерфейса, данные карточки, объяснение full-trust capability, выбор Private audience и итоговая проверка владельцем. После подписи требуются проверки WebView2, localhost, DPAPI, уведомлений, обновления и миграции в установленном пакете. Закрытая аудитория Store и закрытость исходников — разные настройки.

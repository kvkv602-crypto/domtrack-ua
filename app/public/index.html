ВАШИ ДАННЫЕ

Конфиденциальность

DomTrack UA хранит историю объявлений, заметки, избранное, настройки и пороги цен на вашем компьютере. Приложение не отправляет эту базу разработчику и не содержит собственного сервиса рекламы или аналитики.

Необязательный API-ключ RIA шифруется Windows DPAPI для текущего пользователя. Саму базу и заметки приложение отдельно не шифрует. Ключ передаётся только официальному API RIA при его использовании.

Поиск обращается к подключённым сайтам объявлений, курсы валют — к bank.gov.ua. Карта загружает OpenStreetMap. Эти сервисы видят ваш сетевой адрес и соответствующие запросы; их собственные правила конфиденциальности действуют отдельно. Windows и WebView2 также имеют собственные настройки и политику Microsoft.

При запуске обновляется выбранный город. Плановые проверки и слежение за ценами работают, пока приложение запущено. Их можно выключить в настройках и списке отслеживаемых объектов. Экспорт и резервные копии создаются по вашему действию и могут содержать контакты из объявлений и введённые сведения.

Сведения остаются локально, пока вы их не удалите. Перед удалением данных или приложения сохраните нужную резервную копию. Удаление приложения не удаляет аккаунты и данные на сторонних сайтах.

Дата этой редакции: 28 октября 2026 года. Издатель: владелец проекта DomTrack UA, профиль GitHub kvkv602-crypto. Полный текст и сведения о сторонних компонентах входят в файлы PRIVACY.md и THIRD_PARTY_NOTICES.md установленного пакета.

ПОПОЛНИТЬ БАЗУ

Импорт объявлений

Загрузите CSV, JSON с записями или резервную копию DomTrack. Существующие объявления будут дополнены наблюдениями.

Какие поля поддерживаются?

Обязательные: title, city, kind (apartment/house), price, currency и постоянная ссылка url либо externalId. Сделка — sale. Дополнительно: region, rooms, area, floor, floorsTotal, address, observedAt. Для CSV доступны заголовки на русском, украинском и английском; разделитель — запятая или точка с запятой.

DIM.RIA · дополнительный официальный API

Для подключения нужен собственный API-ключ. Доступные объявления и лимиты зависят от API. Это не полный охват рынка Украины. Загрузка с реальным ключом ещё не проверена. После одобрения аккаунта получите ключ в личном кабинете RIA, вставьте ниже и проверьте подключение.

Проверяем состояние…
Ключ сохраняется в зашифрованном хранилище Windows и автоматически загружается при следующем запуске. В браузер обратно не выводится.
Выберите город из справочника

Проверка ключа использует один запрос API. Ключ сохраняется зашифрованным для текущей учётной записи Windows. Для замены вставьте новый ключ; пустое поле сохраняет текущий. ID и названия ниже заполняются при выборе; их можно изменить вручную.

Выберите фактический лимит аккаунта. Локальный счётчик ограничивает запросы DomTrack; остаток в кабинете RIA может отличаться.

Плановая проверка работает, пока запущен локальный сервер приложения.
